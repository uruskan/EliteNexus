From a favourite to your own

Start from a theme. Refine every shade.

Start from the standard orange or a credited community theme such as Mocha, Lemon or Empire blue, then make it feel right for your cockpit.

Colour, saturation, brightness

Turn the colour wheel, lower the saturation to soften a vivid palette, or lower the brightness to dim the whole HUD for a long night in the black. The preview responds as you adjust.

See what changes

Swatches under the preview show what each standard colour becomes: HUD orange, hostile red, friendly green, highlight blue and white. The page warns when hostile and friendly contacts would look alike, or when the HUD gets too dark.

Exact matrix control

Matrix shows the nine numbers behind the theme, for bringing an existing setup across exactly or fine-tuning beyond the simple controls.

Keep the colours that mean something

Blue HUD. Red hostile. No second guess.

The game has one colour matrix for the whole interface, so a blue theme turns hostile contacts blue too: the commonest complaint about themes. Elite Nexus can apply your theme to the HUD’s orange only.

Keep hostile red, friendly green and shield blue

With Elite Nexus’s graphics hook installed and calibrated from the Cockpit lights tab (its dimmer can stay off), the HUD shaders apply the game’s matrix only to the HUD’s orange: hostile contacts stay red, friendly ones green, and shields, other highlights and white keep their standard colours. The preview, the swatches and the warnings then show it that way. The switch is saved as soon as you flip it, and the game picks it up when it next starts.

Whether a colour counts as the HUD’s orange is decided by its green and blue as shares of its red, and Options sets those shares. Frontier documents none of this, so if hostile contacts still change colour or parts of the HUD stay orange, adjust them there.

A theme worth keeping

Save it. Share it. Apply it.

  1. Save your favourites

    Name a theme and choose Save theme. Your own palettes join the presets, ready whenever you want a different cockpit; right-click one to delete it.

  2. Share, or use a shared one

    Copy as XML gives you the three colour-matrix lines commanders post on forums. Found a theme there? Paste its lines into Use a theme someone shared to load it into the editor.

  3. Apply, then restart the game

    Apply to Elite Dangerous writes only the three colour lines of the game’s GraphicsConfigurationOverride.xml and keeps everything else in it; your original file is copied aside the first time. The game reads the file only when it starts, so quit to the desktop and restart to see the change.

Good to know

What it can and can’t do.

Does the preview show exactly how the game will look?

It is an interactive illustration of the colour changes. The game adds glow, transparency and its own rendering, so the final appearance can differ. Check your theme in the game after restarting.

Can I give each HUD element its own colour?

No. The game’s colour matrix affects the whole interface together, including station menus, the on-foot HUD and mission-board portraits, while the main menu stays orange. Elite Nexus can keep the standard contact and highlight colours out of a theme with its graphics hook, but it can’t colour one element on its own, and it can’t dim or recolour the cockpit’s lighting: that is what Cockpit lights is for.

Do ordinary themes need the graphics hook?

No. Themes, brightness and saturation use the game’s own settings file. Only keeping hostile red, friendly green and shield blue needs the optional hook, which can’t run alongside EDHM or another 3Dmigoto mod. If EDHM is installed, the page warns that EDHM needs this setting left at the standard orange.

Does it work on Linux and on a Mac?

HUD colours uses the game’s Options folder inside its Proton, Wine, CrossOver or Whisky prefix, where Elite Nexus finds it. It hasn’t been confirmed with the game there yet; reports are collected in GitHub discussion 17.
